# GameAssets

Generated by `node Tools/build-assets.mjs` from `../Evoker Web/assets` (card art, the original client sprites,
sounds, fonts, map, minions, portraits, animations) plus `manifest.json`. This folder is added to the app as a
folder reference and copied into the bundle as is; `Evoker/Assets/BundleAssetCatalog.swift` resolves every name
through the manifest. To swap the art, replace the files and keep the manifest keys.
