# Round 4 - original stage art found (42 of 153 missing card-stages)

Folder layout: `art-found/<card-id>/<stage>.png` is my crop of the art window from the source image (stage names base, p1 = +, p2 = ++, p3 = +++, p4 = ++++).
`<stage>_src.<ext>` is the untouched wiki download (full card face or phone screenshot, best available resolution).

Quality caveats:
- Nothing on the wiki is the original 541x768 art file. Every found image is a **screenshot of the in-game card**, so the art window is a crop of the card frame
  (about 520-860 px wide, slightly different aspect from 541x768 because the game shows the art in a frame). The red attack-direction arrow at the top centre and,
  in some sources (Dark Mage/Bone/Umbral/Werewolf/Raptorial crops), the tribe icon corner may still intrude a few pixels. Crop rectangles are fractions of the source and can be redone from `_src`.
- Crops for Alex2076 files use x 7.2-93.6 %, y 14.5-82 %; Gothar31 IMG files x 6.7-94 %, y 13.2-95.2 %; art-only files x 7.2-93 %, y 5.8-94.8 %; phone screenshots x 10.8-90.5 %, y 10.8-61.2 %.

## Notes on specific cards

- **Wizard Apprentice**: the wiki page's lead image IMG_1877 (art only, no title, no effects) is the base: a hooded man reading a recipe book with potatoes. It matches the "hooded Legendary" assumption only loosely (not compared against the casino set page frame); stage + and above carry the same scene with progressively more effects, titles read "Wizard Apprentice+/++/+++/++++". Also available: IMG_1873 (same as ++), `5-1512148717.png` (Italian ++++ at level 46, 687x972). The old assets named Wizard_Apprentice+/++ are Cursed Stag art, so replace them.
- **Cursed Stag**: base is IMG_1840 (plain, not mirrored) = what we already have. + is horizontally mirrored versus base (small stag on the right), ++ onward not mirrored. IMG_1875 is a French screenshot of ++ with ability text at level 24.
- **Umbral Dragon**: we already had base and ++ (`Umbral_Dragon++.jpg` from the wiki is a 480x685 screenshot); found +, +++, ++++ from Alex2076's Italian screenshots. A higher-quality ++ is also `3-1.png` (Alex2076, 686x973).
- **Raptorial Fungus**: ++ from Screenshot_20170511-092825, +++ from Screenshot_20170509-064429, ++++ from Screenshot_20170511-163913 (all 720x1280, Alex2076). The + we own is probably the same type of screenshot.
- **Goblin Thieves / Scrapmaster / Harpy / Minotaur / Flameling**: art-only files with the plain card frame, no title text, so the stage comes only from the wiki gallery order/captions (for Goblin Thieves and Scrapmaster: the gallery lists the four plus stages in order, and file names carry the stage number 2-5). Visual effect intensity increases monotonically (sparkles, lightning, magic circle on ++++), consistent with all known ++++ arts.
- **Goblin Mob ++**: `Wp_ss_20160413_0001.png` is captioned "Goblin Mob++" in the wiki gallery.
- Also on the wiki but not needed (already owned / not on the missing list): Alex2076 images of Army of Ghosts + to ++++, Sand Yeti + to ++++, Bone Dragon/Dark Mage base screenshots; Siamese Orc +/++ splash screenshots (1440x2560, ASSTOUNDING) are **+ and ++ again**, not +++/++++. Wheel of Fortune base: IMG_1883.PNG (640x911, art only; we own the base already).
